# Labpur Smart Spatial Decision Support System & 70-Year Audit
**Innovator & Lead Researcher:** Mangal Mondal  
**Location:** Labpur Block, Birbhum, West Bengal  

## Project Summary
This scientific geospatial model was engineered by **Mangal Mondal** for the local administration of Labpur Block. It calculates flood vulnerability zones along the Kuye river basin, formulates safe evacuation routing, and presents a 70-year environmental transformation assessment (1950–2026) with predictive planning for 2036.

- **Author:** Mangal Mondal
- **Platform:** Python GIS Engine (Pydroid 3)
